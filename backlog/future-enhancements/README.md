# Future Enhancements

## Overview
Post-MVP features and improvements to be considered after core functionality is complete.

## Enhancements

### [Full-Text Search](./search.md) - 8 points
Search posts by keyword using PostgreSQL full-text search or SQLite FTS5.

### [Post Categories/Tags](./tags.md) - 8 points
Categorize posts with tags for better content organization.

### [Comment System](./comments.md) - 13 points
Allow readers to leave comments on posts. Consider external service (Disqus) to reduce complexity, or skip entirely per original requirements.

### [Dark Mode](./dark-mode.md) - 5 points
Toggle between light and dark themes for better reading experience.

### [Reading Time Estimate](./reading-time.md) - 2 points
Display estimated reading time for each post based on word count.

## Total Story Points: 36

## Priority
All items are **P3 (Future)** and should only be considered after MVP is complete and deployed.

## Decision Criteria
Before implementing any enhancement, ask:
- Does this serve a real user need proven by data?
- Does it align with the simplicity principle?
- Will it still make sense in 10 years?
- Can it be implemented without adding significant complexity?
